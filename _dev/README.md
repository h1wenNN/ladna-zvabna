# `_dev` — інструменти розробки

**Цю теку НЕ треба викладати на хостинг.** Тут немає нічого, що потрібно
сайту: лише скрипти, якими його перевіряють.

## Запуск

```
cd site
bash checkall.sh
```

Скрипт сам підніме локальний сервер (8899 — звичайний, 8901 — з gzip
і кешуванням, як на хостингу), перезбере `site.min.*` і прожене всі
перевірки. Повний прогін — близько 12 хвилин. Кожна перевірка закінчується
рядком «ПРОБЛЕМ: N».

Потрібен Node.js і playwright:

```
npm i -D playwright && npx playwright install chromium
```

`_browser.js` шукає playwright і Chromium у кількох типових місцях;
якщо браузер лежить деінде — вкажіть шлях змінною `PW_CHROMIUM`.
Адресу сайту можна перевизначити змінною `LZ_URL`.

Окрему перевірку можна запустити напряму:

```
node _dev/checks/layoutcheck.js
W=375,1440 node _dev/checks/layoutcheck.js     # тільки ці ширини
```

## Що перевіряє кожен скрипт

| Скрипт | Що ловить |
|---|---|
| `layoutcheck` | накладання елементів, обрізаний текст, вихід за вікно, дрібні зони дотику — 16 ширин від 320 до 2560 |
| `statecheck`  | те саме у станах: меню відкрите, квіз розкритий, повзунок у крайніх положеннях, шрифт +30%, короткі екрани (телефон у горизонталі) |
| `revealcheck` | чи не лишається щось невидимим після різких переходів: стрибок у низ, перехід за якорем, дуже швидкий скрол |
| `qualitycheck`| розмітка, посилання, доступність, порядок заголовків, фокус із клавіатури, робота без JS і з reduced-motion |
| `menucheck`   | мобільне меню: кнопка закриття, Esc, фокус-трап, перехід за пунктом, швидке закрити→відкрити |
| `mediacheck`  | відео (джерела, швидкість, поведінка при reduced-motion), повзунок «до/після», вхід за адресою з якорем |
| `hitcheck`    | реальні зони натискання пальцем — через `elementFromPoint`, а не за розміром коробки |
| `bandcheck`   | розтушовані краї темних сцен не накривають текст |
| `typocheck`   | висячі короткі слова в кінці рядків — у рендері, а не в коді |
| `fullcheck`   | контраст КОЖНОГО тексту; поверх кадрів — по справжніх пікселях знімка |
| `audit`       | без JS · reduced-motion · повільна мережа · тільки клавіатура |

## `scratch/`

Одноразові скрипти з попередніх сесій: заміри CLS, пошук LCP-елемента,
знімки окремих сцен. Лишені як історія, регулярно не запускаються.
