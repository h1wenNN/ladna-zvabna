# Сайт «Ладна-Звабна»

Салон естетики обличчя та тіла · Бровари, вул. Симоненка, 30А

---

## Як подивитися сайт

**Найпростіше:** двічі клацніть `start.bat` — відкриється браузер із сайтом.
Щоб зупинити, закрийте чорне вікно.

**Якщо `start.bat` не спрацював** (немає Python і Node.js) — просто відкрийте
`index.html` подвійним кліком. Сайт працює й так; різниця лише в тому, що
в консолі браузера буде кілька попереджень про шрифти. На вигляд сторінки
це не впливає.

---

## Як усе влаштовано

```
site/
├── index.html          ← сама сторінка: тексти, ціни, контакти
├── gallery.html        ← галерея справжніх фото салону та догляду
├── start.bat           ← подивитися сайт на своєму комп'ютері
├── build.sh            ← перезбирає стилі та скрипти після правок
├── favicon.ico         іконка вкладки
├── og-cover.jpg        картинка для месенджерів і соцмереж
├── robots.txt          вказівки пошуковим системам
├── sitemap.xml         мапа сайту
└── assets/
    ├── css/            стилі (правити тут) + site.min.css (зібраний)
    ├── js/             скрипти (правити тут) + site.min.js (зібраний)
    ├── fonts/          шрифти
    ├── img/            фотографії та іконки
    ├── video/          короткі відео інтер'єру та процедур
    └── svg/            логотип
```

Сайт не потребує ні бази даних, ні сервера. Це звичайні файли: папку `site/`
можна залити на будь-який хостинг — і вона працює.

## Як поміняти ціну

1. Відкрийте `index.html` у звичайному «Блокноті» або в редакторі коду.
2. Знайдіть потрібну процедуру (Ctrl+F → назва процедури).
3. Поруч буде рядок із ціною, наприклад `<span class="price">1200 грн</span>`.
4. Змініть саме число. Слово «грн» лишіть.
5. Збережіть файл і залийте його на хостинг.

**Не чіпайте** кутові дужки `< >` і лапки — від них залежить, чи не зламається сторінка.

## Як замінити фотографію

Кожне фото на сайті — окремий файл у `assets/img/`.
Щоб замінити кадр, підготуйте нові JPG і WebP **із тими самими назвами**.
Головний кадр має також окрему версію для телефона:
`assets/img/editorial/hero-care-mobile.jpg` і `.webp`.
Звичайна заміна тільки одного JPG не оновить сторінку в браузерах, які показують WebP.

У вересні 2026 року кадри розкладено за змістом: головна — ілюстративний
редакційний кадр масажу обличчя; історія — справжній розпис знака; «Простір» —
кава зі свічкою та зона очікування; «Турбота — у дотику» — справжній кадр догляду
тіла й ілюстративний портрет; «Догляди» — відео процедури обличчя; «Запис» — вхід до салону.
Два редакційні кадри створено генератором зображень. Вони не є фотографіями
салону чи конкретних клієнток; їхні вихідні файли й скрипт кадрування лежать у `_dev/`.
Джерела й причини відбору зазначені в `_dev/MEDIA_AUDIT_2026-09.md`.

### Галерея

Окрема сторінка `gallery.html` містить 10 справжніх кадрів: простір, моменти
догляду, гостинні деталі та вхід. Зображення лежать у `assets/img/gallery/`,
джерела й таймкоди — у `_dev/GALLERY_SOURCES_2026-09.md`.
Редакційні згенеровані портрети до галереї не входять.

Натискання на фото відкриває перегляд із кнопками «Попереднє» й «Наступне»;
працюють також стрілки клавіатури та Escape. Без JavaScript посилання
відкриває файл фотографії. Навігація за розділами працює як звичайні посилання.
Стилі й поведінка галереї — `assets/css/gallery.css` та `assets/js/gallery.js`.

**Вимоги до нових фото:**

- тепле природне світло, без спалаху;
- у кадрі мають бути кольори бренду: молочний, пісочний, оливковий, мідний;
- **без вшитого тексту й написів** — уся типографіка на сайті своя;
- без глянцевого ретушу шкіри «до пластику»;
- бажано по дві версії кожного ключового кадру: вертикальну й горизонтальну.

Повний список кадрів, яких сайту бракує, — у файлі `../PROGRESS.md`,
розділ «Матеріали, яких чекаємо».

## Що не варто робити самостійно

- міняти кольори в `assets/css/` — палітра узгоджена з гайдбоксом бренду;
- додавати нові розділи;
- вставляти віджети, чат-боти, банери й спливні вікна.

Сайт свідомо зроблений тихим. Кожен гучний елемент руйнує саме те відчуття,
заради якого він робився.

## Публічна адреса й пошук

Сайт розміщений на https://ladna-zvabna.pages.dev/ у Cloudflare Pages.
Canonical, Open Graph, дані салону, `sitemap.xml` та `robots.txt` узгоджені
з цією адресою. Cloudflare перенаправляє `gallery.html` на `/gallery`;
саме кінцева адреса записана в canonical і sitemap.

Покрокова інструкція Search Console та список даних для Google Maps —
у `_dev/GOOGLE_SETUP.md`. Підтвердження Google потребує акаунту власника.

Графік у контактах: «за попереднім записом». Реальні дні й години та
актуальність цін має підтвердити клієнтка.

Якщо надалі зміниться домен, оновіть адреси у `index.html`, `gallery.html`,
`sitemap.xml` та `robots.txt`, а також ресурс у Search Console.

## Рекомендації хостингу

Сайт швидкий сам по собі, але два налаштування на боці сервера дають
ще третину швидкості. Покажіть цей абзац тому, хто налаштовує хостинг:

- **увімкнути gzip або brotli** для `.html`, `.css`, `.js`, `.svg`;
- **кешування статики**: для незмінних імен файлів використовуйте перевірку
  оновлень. Річний `immutable` підходить лише файлам з хешем або версією
  в назві, інакше відвідувачі можуть бачити старі фото та стилі.

З цими налаштуваннями Lighthouse на телефоні показує **98 балів
продуктивності**, без них — 95.

## Технічні деталі для розробника

- Чистий HTML + CSS + JS. Без фреймворків.
- Плавний скрол — Lenis (5.4 КБ gzip). GSAP не використовується: пін зроблено
  нативним `position:sticky`, прив'язки до скролу — власним rAF-циклом.
- Шрифти локальні, `woff2`, ліцензія SIL OFL 1.1 (див. `ASSETS.md`).
- Сайт має лишатися повністю читабельним із вимкненим JavaScript
  і при `prefers-reduced-motion`. Це вимога, не побажання.

### Збірка

Стилі та скрипти лежать окремими файлами з коментарями — **правити треба їх**.
Після будь-якої правки в `assets/css/` або `assets/js/`:

```
bash build.sh
```

Скрипт склеїть і стисне їх у `site.min.css` та `site.min.js`, на які
посилається `index.html`. Потрібен Node.js.

**Правки в `index.html`** (ціни, тексти, контакти) збірки **не потребують**.
